## 🧑‍💻 About me

I'm a CSE student at **PES University** who enjoys the whole stack of fundamentals: how an OS schedules things, how a database keeps data consistent, how a weak password gets cracked, and how a model reaches a prediction.

I learn best by building, so my GitHub is a mix of coursework and solo projects across systems, databases, security and data. It's honest, a bit messy, and improving with every commit.

> 💬 *"Gym taught me progressive overload. CS taught me incremental builds. Same lesson: small steps, every day, in the right direction."*
